# تواصل — تطبيق ويب تقدمي (PWA)

سجل الطلاب وأولياء أمورهم، مع إرسال رسالة واتساب أو رسالة نصية بضغطة واحدة.

## محتويات المشروع

```
tawasul/
├─ index.html                 التطبيق كاملًا (الواجهة + المنطق + خط Cairo مضمّن)
├─ manifest.webmanifest       تعريف التطبيق: الاسم، الأيقونات، وضع العرض
├─ sw.js                      عامل الخدمة — يجعل التطبيق يعمل بدون إنترنت
├─ fonts/cairo.woff2          خط Cairo (نسخة مقتصّة على العربية واللاتينية)
├─ vendor/xlsx.full.min.js    مكتبة قراءة ملفات إكسل
├─ icons/                     أيقونات التطبيق بجميع المقاسات (تشمل maskable)
└─ README.md
```

## التشغيل محليًا

عامل الخدمة والتثبيت يحتاجان خادمًا (لا يعملان بفتح الملف مباشرة عبر `file://`):

```bash
cd tawasul
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## النشر والتثبيت

ارفع المجلد كما هو على أي استضافة تدعم HTTPS (GitHub Pages، Netlify، Cloudflare Pages، أو أي خادم).

- **أندرويد / كروم:** يظهر شريط «تثبيت» داخل التطبيق، أو من قائمة المتصفح ← تثبيت التطبيق.
- **آيفون / سفاري:** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

بعد التثبيت يعمل التطبيق بدون إنترنت بالكامل، بما في ذلك استيراد ملفات الإكسل.

## الرسائل الجاهزة

عند الضغط على «واتساب» أو «رسالة» تظهر قائمة القوالب الرسمية (غياب، تأخر، مراجعة المدرسة،
سلوك، تدني مستوى، شكر وتقدير، اجتماع، حالة صحية…) مع خيار **رسالة مخصصة**.
كل رسالة تُبنى تلقائيًا من: ترويسة + نص القالب + توقيع، مع تعبئة اسم الطالب والصف
واسم المدرسة والمرسل والتاريخ، وحذف أي سطر بقي بلا بيانات.

المتغيرات المتاحة داخل القوالب:
`{الاسم}` `{الصف}` `{المرحلة}` `{ولي_الأمر}` `{الطالب}` `{ابنكم}` `{المدرسة}` `{المعلم}`
`{اليوم}` `{التاريخ}` `{التاريخ_الهجري}`

القوالب قابلة للتعديل والحذف والإضافة من: **الإعدادات ← قوالب الرسائل**.

## البيانات

تُحفظ قائمة الطلاب والإعدادات داخل الجهاز فقط. للنقل بين الأجهزة استخدم
**الإعدادات ← تصدير نسخة احتياطية** ثم **استعادة نسخة احتياطية**.
